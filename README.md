# Connect4Game
A complete implementation of Connect Four featuring an AI opponent powered by the Minimax algorithm with Alpha‑Beta pruning.


## how to run

#### Install numpy
```bash
pip install numpy
```

#### Console version

```bash
python main.py  
```
player -> 1 , ai -> 2 

#### GUI version
```bash
python gui.py
```


## Difficulty Levels


| Option       | Description             | 
| ------------ | ----------------------- | 
| 1 - Easy     |  Random moves           | 
| 2 - Medium   | 	Depth 1 search         | 
| 3 - Hard	   | 	Depth 2 search         | 
| 4 - Expert   |  Depth 3 search         |
